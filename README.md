# Пустошь — графические проверки Godot

Приватный репозиторий игры «Пустошь» на Godot 4.7.

## Статус

В репозитории настроена инфраструктура тестирования; игровые ресурсы необходимо загрузить из архива `Pustosh_V6_Godot_Visual_Tests.zip`.

В корне проекта должны находиться `project.godot`, `main.tscn`, `scripts/`, `assets/`; сценарий теста лежит в `ci/`, а GitHub Actions — в `.github/workflows/`.

После загрузки ресурсов запустить графический тест через **Actions → Pustosh V6 - graphical playtest → Run workflow**. Результаты — артефакт `pustosh-visual-test-results` со скриншотами PNG и JSON-отчётом.

Тест использует виртуальный экран Xvfb и программный OpenGL. Сбор ресурсов в тесте пока имитируется подготовкой инвентаря, а крафт выполняется через игровой интерфейс; это не равнозначно свободному управлению героем в реальном времени.

Пока запуск GitHub Actions не завершён успешно, графическую работоспособность нельзя считать подтверждённой.
